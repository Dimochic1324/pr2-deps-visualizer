# deps-graph

Учебный проект — инструмент визуализации графа зависимостей пакетов Python.

Программа получает зависимости пакета из репозитория и строит по ним граф.

## Возможности

На данный момент программа поддерживает:

- конфигурационный файл JSON;
- обработку ошибок в параметрах;
- получение прямых зависимостей пакета из репозитория PyPI;
- построение графа зависимостей алгоритмом DFS;
- ограничение глубины анализа и фильтрацию пакетов;
- обнаружение циклических зависимостей;
- тестовый репозиторий в текстовом файле;
- тестирование с помощью pytest.

## Параметры

Параметры задаются в файле `config.json`:

- `package` — имя анализируемого пакета;
- `repository` — URL-адрес репозитория или путь к файлу тестового репозитория;
- `test_mode` — режим работы с тестовым репозиторием;
- `output_image` — имя файла с изображением графа;
- `ascii_tree` — режим вывода зависимостей в виде ASCII-дерева;
- `max_depth` — максимальная глубина анализа зависимостей;
- `filter` — подстрока для фильтрации пакетов.

## Получение зависимостей

Зависимости берутся из репозитория PyPI без pip и сторонних библиотек.
Программа скачивает страницу `https://pypi.org/pypi/<пакет>/json`
и берёт из неё список `requires_dist`. Необязательные зависимости
(`extra == ...`) пропускаются.

## Граф зависимостей

Граф строится рекурсивным обходом в глубину (DFS). Обход не идёт глубже
`max_depth`, пакеты с подстрокой `filter` в имени пропускаются. Если пакет
встречается в текущем пути обхода второй раз, это цикл — он выводится
на экран, и обход по нему останавливается.

## Тестовый репозиторий

Если `test_mode` равен `true`, в `repository` указывается путь к текстовому
файлу. Пакеты в нём называются большими латинскими буквами:

```text
A: B C
B: D
C: D E
```

Примеры лежат в папке `repos/`.

## Запуск

```text
python src/main.py --config config.json
```
